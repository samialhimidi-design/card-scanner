# سكانر البطاقات (Card Scanner) — تطبيق Flutter

تطبيق يتصل بطابعة/سكانر شبكي محلي (بدون كاميرا)، يمسح وجهي البطاقة بشكل منفصل،
ثم يدمجهما في صفحة PDF واحدة بحجم A4 بنفس جودة وألوان السكانر الأصلية.
يعمل بالكامل بدون إنترنت (فقط شبكة الواي فاي المحلية)، والبيانات تُحفظ على الجهاز فقط.

## آلية العمل (نظرة عامة)

1. **اكتشاف الطابعة**: البحث عن طابعات تدعم بروتوكول **eSCL** (نفس بروتوكول AirPrint Scan)
   على شبكة الواي فاي عبر mDNS، أو إضافتها يدوياً بعنوان IP.
2. **مسح الوجه الأمامي** ثم **مسح الوجه الخلفي** بشكل منفصل عبر طلبات HTTP لبروتوكول eSCL.
3. **الدمج**: بناء صفحة PDF واحدة (A4) تحوي الصورتين، بترتيب عمودي أو أفقي حسب اختيار المستخدم.
4. **دعم تجميع عدة بطاقات بملف واحد**: يمكن إضافة بطاقة تلو الأخرى قبل الحفظ النهائي، فتُحفظ كل بطاقة كصفحة منفصلة داخل نفس ملف PDF.
5. **الحفظ**: الملف يُخزَّن محلياً فقط داخل مجلد التطبيق، مع إمكانية المشاركة/الطباعة من داخل التطبيق.

## المكتبات المستخدمة (كلها مكتبات رسمية/مشهورة على pub.dev)

| المكتبة | الاستخدام |
|---|---|
| `multicast_dns` | اكتشاف الطابعات على الشبكة (mDNS/Bonjour) |
| `http` | إرسال طلبات بروتوكول eSCL للطابعة |
| `pdf` | بناء ملف PDF ودمج صورتي البطاقة في صفحة واحدة |
| `printing` | عرض/مشاركة/طباعة ملف الـ PDF داخل التطبيق |
| `path_provider` | تحديد مسار التخزين المحلي على الجهاز |

## خطوات التشغيل

> **ملاحظة مهمة**: هذا المشروع يحوي كود Dart (مجلد `lib/`) و`pubspec.yaml` فقط،
> وليس مشروع Flutter كامل (لا يحوي مجلدي `android/` و `ios/` الضخمين
> اللي يولدهم أمر `flutter create` تلقائياً). اتبع الخطوات بالترتيب:

### 1. تثبيت أدوات التطوير (إن لم تكن مثبتة)
- ثبّت [Flutter SDK](https://docs.flutter.dev/get-started/install)
- ثبّت Android Studio (لأندرويد) و/أو Xcode (لآيفون، يتطلب جهاز Mac)

### 2. إنشاء مشروع Flutter فارغ
```bash
flutter create card_scanner_app
cd card_scanner_app
```

### 3. استبدال الملفات
- احذف محتوى مجلد `lib/` الافتراضي، وانسخ مكانه مجلد `lib/` المرفق هنا بالكامل
- استبدل ملف `pubspec.yaml` بالملف المرفق هنا (احتفظ بحقل `name:` كما ولّده Flutter لو اختلف)

### 4. تفعيل صلاحيات الشبكة المحلية
- **أندرويد**: افتح `android/app/src/main/AndroidManifest.xml` وأضف الأسطر
  الموجودة في `docs/android_manifest_additions.xml`
- **آيفون**: افتح `ios/Runner/Info.plist` وأضف المفاتيح
  الموجودة في `docs/ios_info_plist_additions.xml`

### 5. تحميل الحزم
```bash
flutter pub get
```

### 6. التشغيل
```bash
flutter run
```
تأكد أن الجوال متصل بنفس شبكة الواي فاي التي تتصل بها الطابعة.

## هل ستعمل مع أي طابعة؟

يعتمد التطبيق حصراً على بروتوكول **eSCL**، وهو مدعوم من أغلب طابعات/سكانرات
المكاتب الحديثة (HP, Canon, Epson, Brother, Xerox...) المنتجة تقريباً من 2013 وما بعد.
**الطابعات القديمة جداً أو التي لا تدعم eSCL لن تعمل** مع هذا التطبيق كما هو،
وتحتاج بروتوكول إضافي (WSD أو SDK خاص بالشركة المصنعة) — وهذا خارج النطاق الحالي.

نصيحة: قبل الاعتماد الكامل على التطبيق، جرّب فتح الرابط التالي من متصفح الجوال
(وهو نفس الشبكة) للتأكد أن الطابعة تستجيب لبروتوكول eSCL:
```
http://<عنوان-IP-للطابعة>/eSCL/ScannerCapabilities
```
لو ظهر لك ملف XML، فالطابعة مدعومة.

## نقاط للتطوير المستقبلي (غير مضمّنة حالياً)

- اكتشاف تلقائي لحواف البطاقة وقصّها (Auto Crop) من الصورة الممسوحة إن كانت الطابعة
  تمسح كامل مساحة الفليتبد بدل حجم البطاقة فقط
- حفظ تفضيلات كل طابعة (آخر طابعة مستخدمة) لتسريع الاستخدام المتكرر
- دعم بروتوكول WSD كبديل احتياطي للطابعات التي لا تدعم eSCL
